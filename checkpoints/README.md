# Checkpoints directory

This directory stores exported intermediate artifacts from the learning pipeline.

## Main file

### `experiment_checkpoint.pkl`
Generated by `02_Data_Driven_IRL.ipynb` and consumed by `03_Benchmarking_and_Plots.ipynb`.

The checkpoint is intended to store the minimum set of learned objects and benchmark targets needed to reproduce the benchmark pipeline without retraining.

Typical contents may include:
- learned transition / observation structures,
- learned reward information,
- simulation environment parameters,
- benchmark-alignment targets,
- calibration statistics used by the benchmarking notebook.
