# Data directory

This directory separates raw inputs from processed artifacts used by the learning and benchmarking notebooks.

## Structure

- `raw/`: original inputs or placeholders for original inputs.
- `processed/`: derived datasets generated by `02_Data_Driven_IRL.ipynb`.

## Processed files

### `clean_movie_52_with_speed.csv`
Trajectory table after preprocessing, including cleaned positional and kinematic information.

### `clean_movie_52_with_speed_and_action.csv`
Processed trajectory table with action labels added for downstream learning and benchmarking.

## Usage

- `02_Data_Driven_IRL.ipynb` writes the processed files.
- `03_Benchmarking_and_Plots.ipynb` reads them.
