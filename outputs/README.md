# Outputs directory

This directory stores generated artifacts from the benchmarking and supplementary notebooks.

## Structure

- `paper_figures/`: paper-aligned plots and selected supplementary plots.
- `trajectories/`: exported rollout trajectories.
- `tables/`: benchmark summaries and numeric comparison tables.

## Typical files

### `figures/`
Examples:
- alignment histograms
- CDF comparisons
- Q-Q style comparisons
- selected trajectory plots used in the paper

### `trajectories/`
Examples:
- learned policy trajectories
- standard Gillespie trajectories
- modified Gillespie trajectories
- calibrated-policy trajectories

### `tables/`
Examples:
- benchmark summary statistics
- tumble-ratio calibration summary
